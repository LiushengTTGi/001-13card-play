# 开心十三张 (kuaile13)

一个用 Go 写的「开心十三张」：编译出来是**单个可执行文件**，启动后在本机开一个 HTTP 服务，
自动用浏览器打开牌桌。你坐 0 号位，另外三家是电脑玩家：**王五**（下家）、**张三**（对家）、**李四**（上家）。

- 完整的 13 张规则内核：♦2 先出、七种牌型（单张/对子/顺子/同花/同花顺/三带二/四带一）、按出完顺序结算
- 三名会算牌的电脑对手（跟牌、留牌、抢出完时机）
- 网页牌桌 UI：6 秒入场动画、手牌选择、提示、出牌、动作记录、积分累计
- 积分跨会话保持（刷新页面不丢失），支持一键清零
- 零外部依赖，只用 Go 标准库；网页资源通过 `go:embed` 打进二进制

## 快速开始

### 下载可执行文件

到 [Releases](../../releases) 下载对应平台的二进制，双击运行即可：

```
开心十三张 0.1.0 已启动: http://127.0.0.1:8362/
关闭此窗口即可退出游戏。
```

浏览器会自动打开；没打开的话手动访问上面那个地址。关闭终端窗口就退出游戏。

### 从源码运行

需要 Go 1.23 或更高版本：

```bash
git clone https://github.com/kuaile13/kuaile13.git
cd kuaile13
go run .
```

## 命令行参数

| 参数 | 默认值 | 说明 |
| --- | --- | --- |
| `-port` | `8362` | 监听端口，`0` 表示自动选一个空闲端口 |
| `-host` | `127.0.0.1` | 监听地址，改成 `0.0.0.0` 可以让局域网里的其他设备访问 |
| `-bet` | `1` | 每家下注倍数；本局结束后也能在牌桌上选，下一局生效 |
| `-think` | `700ms` | 电脑每家出牌之间的间隔，调小可以让牌局更快 |
| `-no-browser` | `false` | 只启动服务，不自动打开浏览器 |
| `-version` | `false` | 打印版本号 |

## 玩法

四人各 13 张，用完一副 52 张牌（不含大小王）。

**开局**：持有 ♦2 的玩家先出第一张，之后按逆时针 0 → 1 → 2 → 3 轮转。

**出牌**：轮到你必须出牌；别人出过后可以选择「不出」。一轮里其他三家都不压时，
最后出牌的人拿下这一轮并继续先出——如果他已经出完手牌，则由下一家接着先出。

**牌型**（1 张、2 张、5 张三种张数，不同张数之间不能互压）：

| 牌型 | 组成 | 怎么比大小 |
| --- | --- | --- |
| 单张 | 任意一张 | ♦2 最小，♠A 最大；点数相同比花色 ♦ < ♣ < ♥ < ♠ |
| 对子 | 两张同点数 | 按点数；点数相同（各家各持两张）比其中较大的花色 |
| 五张顺子 | 五张点数连续、花色不全相同 | 按最大点数；A-2-3-4-5 最小，10-J-Q-K-A 最大 |
| 五张同花 | 五张同花色、不连续 | 按点数从大到小逐张比，再比花色 |
| 五张同花顺 | 五张同花色且连续 | 同顺子 |
| 三带二 | 三张同点数 + 一对 | 按三张的点数 |
| 四带一 | 四张同点数 + 一张单牌 | 按四张的点数 |

五张牌型之间是绝对阶梯：**四带一 > 三带二 > 同花顺 > 同花 > 顺子**。
也就是说最弱的四带一（3-3-3-3 带 9）照样压得过最强的三带二（A-A-A 带 K 对）。
三张、四张都不能单独出，两张只认同点数。

**结算**：按出完手牌的先后定名次，只剩一家时本局直接结束，那家算最后一名。

| 名次 | 输赢 |
| --- | --- |
| 第 1 名 | 收取另外三家输掉的分数之和 |
| 第 2 名 | 输掉自己下注的 2/4 |
| 第 3 名 | 输掉自己下注的 2/4 |
| 第 4 名 | 输掉另外三家下注之和 |

每家下注可以不同，赢家拿到的正好是另外三家输掉的，所以每一局都是零和。
积分会跨局累计，牌桌上的「清零积分」可以重来。

## 玩法示例

**开局**：四家各 1000 分，下注 1 倍。持有 ♦2 的王五先出。

**第一轮**：
- 王五出单张 ♦2
- 张三出单张 ♦5（压过）
- 李四出单张 ♥5（压过）
- 你不出
- 李四拿下这一轮，继续先出

**第二轮**：
- 李四出对子 ♣8-♠8
- 王五出对子 ♥9-♦9（压过）
- 张三出对子 ♣10-♦10（压过）
- 你出对子 ♥J-♦J（压过）
- 其他三家都不出
- 你拿下这一轮，继续先出

**提示功能**：轮到你出牌时，点击「提示」按钮，系统会自动选出一组能压过桌面的最小牌型。如果手里没有能压过的牌，提示会选中「不出」。

**清零积分**：
- 打了五局后，你发现积分差距太大，想重新开始
- 点击牌桌右上角的「清零积分」按钮
- 四家积分全部回到 1000，当前局作废，重新发牌
- 清零操作不可撤销

**跨会话保持**：
- 打到一半关闭浏览器，明天再打开
- 访问同一地址，积分和局数都还在
- 继续上一局的进度玩

## 项目结构

```
main.go                 启动：读参数、挂内嵌网页、开浏览器
internal/cards          牌、花色、点数、手牌工具（排序/包含/移除）
internal/combo          牌型识别、比大小、枚举所有合法出法
internal/game           一局流程：出牌/不出、轮次推进、名次与结算
internal/ai             三名电脑对手的出牌策略
internal/server         HTTP 接口、内嵌资源、电脑时钟
web/                    牌桌页面（原生 HTML/CSS/JS，无构建步骤）
build.sh                本机或交叉编译
```

## HTTP 接口

牌桌前端用的就是这几个接口，可以直接用 curl 试：

| 方法 | 路径 | 说明 |
| --- | --- | --- |
| `GET` | `/api/state?since=<seq>` | 返回当前牌桌快照，以及序号大于 `since` 的动作记录 |
| `POST` | `/api/play` | `{"cards":["d3","h4","c5","s6","d7"]}` 出牌 |
| `POST` | `/api/pass` | 不出 |
| `POST` | `/api/hint` | 提示一手能出的牌 |
| `POST` | `/api/restart` | `{"bet":2,"resetScores":false}` 开下一局 |

牌面用「花色首字母 + 点数」表示：`d3` = ♦3、`c10` = ♣10、`hJ` = ♥J、`sA` = ♠A。
`/api/state` 只会公开你自己在 0 号位的手牌，另外三家的牌是隐藏的。

## 开发

```bash
go test ./...                       # 规则内核与接口的单元测试
go vet ./...
```

编译当前平台：

```bash
bash build.sh
```

交叉编译发布用的多平台二进制（产物在 `bin/`）：

```bash
VERSION=v0.1.0 bash build.sh windows-amd64 darwin-arm64 darwin-amd64 linux-amd64
```

改动规则内核时建议先看 `internal/combo/combo_test.go` 和 `internal/game/game_test.go`，
里面用 `NewWithHands` 固定了手牌，可以精确复现某一局的出牌和算分路径。
